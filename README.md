# DalitzPlotFitter

DalitzPlotFitter is a Python package under development for unbinned amplitude fits of three-body decays. The numerical pipeline is JAX end to end: phase-space generation, four-momentum kinematics, amplitudes, normalization, likelihoods and gradients all run on the active JAX device. `iminuit` performs minimization and `particle` supplies standard particle properties.

There is no TensorFlow dependency or mixed TensorFlow/JAX numerical path.

Laura++ is one of the main physics references used to define and validate resonance, barrier-factor and angular conventions, but implementation classes use neutral names rather than backend/reference-specific names.

## High-level API

The preferred interface is channel driven:

```python
from dalitzplotfitter import (
    DecayChannel,
    DecayModel,
    NonResonant,
    RealImag,
    Resonance,
)

channel = DecayChannel("D+", ("pi-", "pi+", "pi+"))

model = DecayModel(
    channel,
    [
        Resonance("rho(770)0", pair=(0, 1), coefficient=RealImag(1.0, 0.0)),
        NonResonant(RealImag(0.2, -0.1)),
    ],
)

pdf = model.pdf()
```

`DecayChannel` resolves the parent and daughter masses from the `particle` package. `Resonance` resolves resonance mass, width and spin from `particle` unless an analysis-specific override is supplied.

Historical or analysis-specific values are explicit overrides, for example:

```python
Resonance(
    "sigma",
    pair=(0, 1),
    coefficient=RealImag(x, y),
    mass=0.478,
    width=0.324,
    spin=0,
)
```

## Normalization methods

The project supports two normalization strategies:

1. fixed weighted phase-space Monte Carlo generated by `PhaseSpaceMC`;
2. deterministic equal-area `DalitzGrid` quadrature.

Both are represented internally as a fixed `PhaseSpaceSample`, so the cache, coherent normalization matrix and likelihood use the same numerical interface.

For MC normalization:

```python
norm = model.generate_phase_space(1_000_000, seed=2027)
cache = model.prepare_cache(data, norm)
```

For deterministic grid normalization:

```python
from dalitzplotfitter import DalitzGrid

norm = DalitzGrid(
    channel.parent_mass,
    channel.daughter_masses,
    resolution=1000,
).sample()
cache = model.prepare_cache(data, norm)
```

The normalization sample is fixed during minimization in both cases.

## Component normalization convention

The default amplitude convention is

```text
integral dPhi |F_j|^2 = 1
```

for every dynamical component before the complex coefficient is applied. This keeps the scale of `RealImag` coefficients stable when lineshape parameters such as pole mass or width float.

`DecayModel` owns a weighted phase-space integration sample for its default MC-normalized PDF. The public defaults are

```python
model = DecayModel(
    channel,
    components,
    normalize_components=True,
    normalization_size=1_000_000,
    normalization_seed=2027,
)
```

The sample is generated lazily and reused for the lifetime of the model. An explicit MC or grid sample passed to `prepare_cache` or `pdf` overrides this default normalization support.

Detector efficiency is not included in the individual component normalization. It enters only the total PDF normalization.

## Architecture

```text
DecayChannel + amplitude-component declarations
        -> particle masses / widths / spins
        -> pure-JAX three-body phase space / Dalitz grid
        -> resonance lineshape
        -> Blatt-Weisskopf factors
        -> angular factor
        -> automatic identical-particle symmetrization
        -> unit-integral component normalization
        -> RealImag coefficient
        -> coherent amplitude
        -> normalized SignalPDF
        -> JAX NLL + automatic gradients
        -> iminuit
```

## Pure-JAX weighted phase-space Monte Carlo

`PhaseSpaceMC` implements three-body Lorentz-invariant phase space directly in JAX. It factorizes

```text
dPhi3 = ds12/(2*pi) * dPhi2(P -> R12 3) * dPhi2(R12 -> 1 2)
```

and returns the exact phase-space importance weight for each generated point. For Monte Carlo normalization,

```text
N(theta) proportional to sum_k w_PS(k) |A(x_k; theta)|^2.
```

Unweighted pseudo-data are produced from a larger weighted pool using

```text
w_target(k) = w_PS(k) |A(x_k; theta_gen)|^2
```

followed by `weighted_resample()`.

## Deterministic Dalitz grid

`DalitzGrid` constructs an equal-area grid in transformed Dalitz coordinates. A resolution `N` gives exactly `N**2` physical integration points with constant quadrature weights. Details are in `docs/dalitz_grid_integration.md`.

## E791 examples

The examples are organized in matched grid/MC pairs so that only the normalization method changes:

- `notebooks/02_fit_dynamic_parameters.ipynb`: coefficient-only closure with deterministic `DalitzGrid` normalization;
- `notebooks/02b_e791_coefficient_fit_mc_normalization.ipynb`: the same coefficient-only closure with fixed MC normalization;
- `notebooks/07_e791_rho1450_mass_width_closure.ipynb`: coefficients plus `rho(1450)` mass and width with deterministic grid normalization;
- `notebooks/07b_e791_rho1450_mass_width_mc_normalization.ipynb`: the same dynamical-parameter closure with fixed MC normalization.

The MC-normalized examples use an independent normalization sample (`seed=2027`) and toy-generation pool (`seed=2000`). Both are frozen after generation, so the likelihood remains deterministic during Minuit minimization.

## Coefficients

The supported complex coefficient parameterization is

```text
c = x + i y
```

through `RealImag`. `x` and `y` may be constants or fit `Parameter` objects.

## Installation

```bash
git clone https://github.com/JuanBSLeite/DalitzPlotFitter.git
cd DalitzPlotFitter
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
pytest
```

Double precision is recommended:

```python
from dalitzplotfitter import enable_x64
enable_x64()
```
