# QMI review — 2026-09-09

Historical review of one-dimensional QMI preparation, parameters, gradients and amplitude-cache/FitSession integration. QMI2D tests also ran; deeper inspection focused on QMI 1D. Separate CPU processes used two cores. Applied corrections follow the original findings.

## 1. High: prepared-data collisions between QMI components

`ResonanceAmplitude` originally keyed prepared lineshape data only by the kinematic pair. Sequential preparation reused the first component's indices, fractions and groups for a different knot grid, making the sum depend on component order before minimization.

Reproduction: D+ -> pi- pi+ pi+, pair (0,1), Cartesian grids (0.3,0.7,1.6) and (0.3,1.2,1.6), real values (1,0.2,0.8), imaginary values (0,0.3,-0.2), first real node free as Parameter.dynamics in each component. Coefficients were 1+0i, component normalization disabled, Square-Dalitz resolution 16, 30 data events, seed 46.

| Order | Direct normalization | Cached normalization | Relative error |
|---|---:|---:|---:|
| q1,q2 | 25.4936253905 | 21.8631206491 | -14.2408% |
| q2,q1 | 25.4936253905 | 30.8676404970 | +21.0798% |

Maximum intensity differences were 2.56994 and 4.10903. A single QMI component does not trigger this collision.

## 2. High: incorrectly classified free nodes were silently frozen

Generic `Parameter('knot.x',1,owner='qmi')` defaults to OTHER, while the cache reevaluates only DYNAMICS parameters. Direct evaluation changed with the node; cached evaluation retained its nominal value.

For nodes (0.3,0.8,1.6), real values (generic Parameter,0.6,0.2), imaginary values (0.1,0.2,0.3), without component normalization, the direct/cached difference was 4.44e-16 at x=1 and 4.72277 at x=2. No configuration error was raised. Correctly declared `Parameter.dynamics(...,owner=component_name)` worked.

## 3. Non-identifiable overall node scale

When all nodes are free and the component is normalized, multiplying all Cartesian nodes, or all polar magnitudes, by a common positive factor leaves the normalized amplitude unchanged. Fixing the global coefficient alone does not remove this direction.

Linear/cubic/hermite, polar/Cartesian checks with a fixed NR component gave delta NLL=0 after multiplying QMI scale by two. This can destabilize covariance/HESSE, but is a model-identifiability issue rather than an interpolation error. Choose an appropriate node-scale constraint or disable component normalization and control coefficient/reference redundancies. Do not fix an unnecessary relative phase.

The inspected `23_b2pipipi_qmi_isobar_closure_no_cp.ipynb` already used `normalize_component=False`, so this mechanism was not automatically attributed to its results.

## 4. Non-finite knots were accepted

Ordering/positivity comparisons did not reject (0.3,NaN,1.2) or (0.3,0.8,Inf). Explicit finiteness validation was needed, including QMI2D edges.

## Applied corrections

Prepared lineshape keys are unique per ResonanceAmplitude, while compatible kinematics remain shared. QMI and QMI2D reject free nodes of a kind other than DYNAMICS; generic fixed parameters remain allowed. Non-finite knots/edges are rejected. Scale conventions are documented without imposing an automatic physical constraint.

## Validation and limits

Initially **34 existing tests passed in 24.92 s** (`test_qmi`, `test_qmi2d`), plus 12 additional scenarios: linear/cubic/hermite × Cartesian/polar × component normalization on/off. These used correctly classified parameters, three nodes, QMI plus NR, 32 events (seed 113) and resolution-16 integration. Cached/direct PDF tolerances were 1e-11; finite-difference gradient tolerances were rtol=1e-6, atol=1e-7, relative step 1e-5, with observed absolute errors around 1e-9.

After corrections, **79 tests passed in 51.09 s**, covering `test_qmi_regressions`, `test_qmi`, `test_qmi2d`, `test_resonance_amplitude`, `test_amplitude_cache`, `test_workflow`. Regressions include different grid lengths, reversed order, fixed/free dynamics and invalid declarations/values.

These tests do not certify production-grid accuracy, statistical coverage or absence of local minima. Integration grids are not automatically aligned to QMI knots. `cubic` is local smoothstep with zero node slopes; `hermite` uses neighboring slopes. The subsequently added `natural` option is a global natural cubic spline; see `docs/lineshapes.md`. Polar phases are real unwrapped inputs: changing a node by 2*pi can change the interpolated curve.
